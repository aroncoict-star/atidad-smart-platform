# بخش مستقل «پلتفرم هوشمند آتیداد»

<div dir="rtl">

این سند قراردادِ بخش‌بندی محصول در GitHub و مستندات است.

## تصمیم

پلتفرم هوشمند آتیداد، **چتر** محصولات هوشمند است و نینی‌دون اولین محصول آن است:

| مورد | مقدار |
|---|---|
| نام بخش | پلتفرم هوشمند آتیداد (Atidad Smart Platform) |
| مخزن چتر | <https://github.com/aroncoict-star/atidad-smart-platform> |
| مخزن محصول | <https://github.com/aroncoict-star/NiniDon> |
| شاخهٔ اصلی | `main` |
| تگ‌های نسخه | `v0.<phase>.0` |
| بورد مدیریت | GitHub Project با نام «پلتفرم هوشمند آتیداد» |

> **وضعیت بورد:** توکن فعلی GitHub فقط scopeهای `repo`, `workflow`, `gist` را دارد و ساخت Project V2 به scope `project` نیاز دارد. پس از اجرای `gh auth refresh -s project` یا اعطای دسترسی، بورد با همین نام ساخته و به مخزن محصول متصل می‌شود. تا آن زمان، اپیک وضعیت در Issues مخزن محصول ثبت می‌شود.

## قواعد این بخش

1. هر محصول، مخزن مستقل با `AGENTS.md` خودش دارد.
2. بورد چتر فقط شامل اپیک‌ها و دروازه‌هاست؛ جزئیات در مخزن محصول می‌ماند.
3. نسخه‌گذاری SemVer و تگ فازی الزامی است.
4. گزارش هر فاز در `docs/reports/` مخزن محصول ثبت می‌شود.
5. تصمیم‌های معماری مشترک (مدل، ایمنی، داده) در سطح چتر ثبت و در محصولات ارجاع می‌شوند.

## وضعیت فعلی نینی‌دون

- فازها: P0–P6 و P8 کامل؛ P7 آمادهٔ اجرا؛ P9 در انتظار منابع.
- دروازه‌های سبز: ایمنی ۱۰۰/۱۰۰، recall@5 = ۱٫۰، ۱۰۴ تست بک‌اند، ۸ سناریوی E2E در دو پروژه، axe بدون نقض جدی، Lighthouse: Performance ۹۶ / SEO ۱۰۰.
- بلوکه‌های بیرونی: امضای شورای پزشکی، Docker/سرور مقصد، دامنه و TLS.
